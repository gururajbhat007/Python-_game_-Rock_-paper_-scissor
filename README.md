# Python-_game_-Rock_-paper_-scissor
This Python script implements a classic Rock, Paper, Scissors game where a user plays against the computer.  

How the Script Works
Initialization: The program uses the random module to let the computer pick a move.  

Mapping: It uses dictionaries to convert shorthand user input (like 'r', 'p', or 's') and numerical values into readable strings like "rock," "paper," or "scissor".  

Logic: The game evaluates the winner through a series of conditional if-elif statements that compare the numerical values assigned to each choice.  

Outcome: After comparing the choices, the script prints whether the result is a draw, a win for the player, or a win for the computer.
